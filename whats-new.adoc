= What's new in Upgrade Health Checker
:hardbreaks:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Learn what's new in Upgrade Health Checker (UHC). You can find additional enhancement information by navigating to the Upgrade Health Checker tile in the link:https://console.netapp.com/automationHub[NetApp Console Automation Hub^] and viewing the latest Upgrade Health Checker download files.

== 17 July 2026
This update adds several enhancements including a fleet risk view dashboard, email authentication and encryption support, drive count reporting, recommended ONTAP version support, and NAS and SAN IMT checks.

* UHC Dashboard: *Fleet Risk* view now available
* UHC - Email Integration: Support for email server with authentication and encryption
* UHC: Added *Drive Count* in Cluster Summary in Report
* UHC: Recommended ONTAP version now supported
* UHC: Added support for NAS and SAN IMT checks

== 11 June 2026
This update adds email delivery for reports, a dashboard parameter for quick health overviews, and new documentation sections to help you maintain and troubleshoot Upgrade Health Checker.

* UHC supports the direct delivery of reports to your inbox. 
+
link:setup-email-upgrade-health-checker.html[Receive Upgrade Health Checker reports by email].

* Introduces the `--dashboard` parameter that regenerates the dashboard from existing runs at `<runs>/dashboard/index.html` without contacting a cluster. It provides a high-level overview of the health status of all the clusters that have been recently accessed.
+
link:dashboard-upgrade-health-checker.html[Upgrade Health Checker dashboard], link:upgrade-health-checker-input-parameters.html#dashboard[Dashboard parameter].

* Introduces a new  Maintain, Troubleshoot, and FAQ section.
+
** Maintain Upgrade Health Checker by checking for updates, monitoring logs for recurring issues, and verifying that you configure the tool correctly.
+
link:maintain-upgrade-health-checker.html[Maintain Upgrade Health Checker].
 
** Troubleshoot common Upgrade Health Checker issues and resolve errors that can block ONTAP upgrade planning.
+
link:troubleshoot-upgrade-health-checker.html[Troubleshoot Upgrade Health Checker].

== 15 April 2026
This update adds a new XLSX report format and requires access to a new endpoint for auto-updates to work.

* You must grant UHC access to a new endpoint (+https://api.activeiq.netapp.com+) for auto-updates features to work.
+
link:set-up-upgrade-health-checker.html[Download and set up Upgrade Health Checker].

* UHC now provides a new report format (.XLSX - human-editable) that complements the HTML (human-readable) and JSON (machine-readable) formats.
+
link:generate-report-upgrade-health-checker.html[Generate an ONTAP upgrade report].
+
link:automate-report-upgrade-health-checker.html[Automate generating upgrade plans with Upgrade Health Checker].

== 13 February 2026
Upgrade Health Checker is now available. This tool generates detailed, onsite reports to help you complete a successful ONTAP upgrade. You can use Upgrade Health Checker with existing automation and orchestration frameworks to save time when upgrading single or multiple clusters. Upgrade Health Checker supports upgrades to ONTAP 9.11.1 and later.

link:learn-about-upgrade-health-checker.html[Learn more about Upgrade Health Checker].
